

\# SmartSpend



\*\*A Microservices-Based Personal Expense Analytics Platform\*\*



\## Overview

SmartSpend is a web application that helps users record income and expenses, manage monthly budgets, visualize spending patterns, and receive budget alerts.



\## Objectives

\- Manage income and expense transactions.

\- Create monthly budgets.

\- Analyze category-wise spending.

\- Generate budget alerts.

\- Demonstrate containerization, CI/CD and DevSecOps.



\## Technology Stack

\- Frontend: HTML, CSS, JavaScript

\- Backend: Python, FastAPI

\- Database: SQLite

\- Containers: Docker, Docker Compose

\- CI/CD: GitHub Actions

\- Infrastructure as Code: Terraform

\- Security: Bandit, pip-audit, Trivy



\## Microservices

1\. Expense Service

2\. Budget Service

3\. Analytics Service

4\. Alert Service
